# 虫ペット 〜カブト・クワガタ育成記〜

2000年代の「虫ペット」風、カブトムシ・クワガタの育成ゲームです。ブラウザだけで遊べます。

## 遊び方

https://shintaro060709-art.github.io/mushi-pet-game/ を開くだけです。インストール不要、スマホ対応。

## 内容

- 卵を選んで幼虫を育て、さなぎを経て成虫に羽化
- えさやり・トレーニング・なでる・休憩でお世話
- 満腹度・スタミナ・きげんを高く保つほど、生まれる成虫のレア度が上がる
- 無理なトレーニングは、けが・まれに死亡のリスクあり
- 育てた成虫でCPU対戦
- 図鑑・卒業した虫の記録

セーブデータはブラウザの localStorage に保存されます。
